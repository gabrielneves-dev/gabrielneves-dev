## 🚧 Projeto em Destaque

### ⛏️ Veltrix

Um projeto de servidor de Minecraft desenvolvido em conjunto com amigos, com foco em criar uma experiência completa baseada em economia, progressão e interação entre jogadores.

O projeto envolve a criação e integração de diferentes sistemas, incluindo:

* 💰 Economia baseada em mineração, agricultura e comércio
* 🏪 Sistema de lojas e comércio entre jogadores
* 🏡 Proteção e gerenciamento de terrenos
* 📈 Ranks e progressão
* 🎯 Quests e objetivos
* ⚔️ Habilidades e sistemas de progressão
* 🔧 Desenvolvimento e integração de plugins

O Veltrix representa uma parte importante da minha evolução como desenvolvedor, permitindo aplicar conceitos de **Java, orientação a objetos, APIs e desenvolvimento de sistemas** em um projeto de maior escala.
